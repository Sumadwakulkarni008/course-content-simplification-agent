# Course Content Simplification Agent

## Project
An AI-powered educational assistant that simplifies complex academic content into clear, concise, easy-to-understand explanations for students with different levels of prior knowledge.

## Problem Statement
Students often find complex academic and technical content difficult to understand because of terminology, dense explanations, and different levels of prior knowledge.

## Proposed Solution
The Course Content Simplification Agent uses AI to explain academic content in simpler language. It can provide beginner-friendly explanations while preserving the important concepts.

## Main Features
- Simplifies complex academic content
- Uses beginner-friendly language
- Explains key concepts clearly
- Provides structured explanations
- Helps students with different levels of prior knowledge

## Technology
- IBM watsonx Orchestrate
- Generative AI / Large Language Model
- Knowledge source for course content

## Deployment
The agent was built, evaluated, versioned, and deployed to the Live environment in IBM watsonx Orchestrate.

## Evaluation
A test was created for:
"Explain machine learning in simple words for a beginner."

The completed evaluation achieved a 100% success rate for 1 successful test out of 1 total test.
